# 体验与设计候选模板

当前成熟度：`candidate`

本目录把 [体验与设计工程](../../13_体验与设计工程/README.md) 转换为项目可填写的资产：

- [产品设计系统模板](产品设计系统模板.md)；
- [页面设计规范模板](页面设计规范模板.md)；
- [跨平台适配矩阵模板](跨平台适配矩阵模板.md)；
- [视觉与体验验收记录模板](视觉与体验验收记录模板.md)。

使用规则：

1. 模板必须引用当前产品、设计系统、高保真和代码版本；
2. 小任务可以裁剪，但目标、平台、状态、验收和责任不能删除；
3. 不适用项必须说明理由；
4. 模板不会自动产生高质量设计，仍需人工判断和真实设备验收；
5. 经过 YouYu 参考验证前不得提升成熟度。
